# Kusal Wijayawardena — Cybersecurity Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `assets/` — add images, diagrams and project screenshots here

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Push these files to the root of the public repository `kusal-dev.github.io`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. The expected URL is `https://kusal-dev.github.io/`.

## Before publishing
- Check all personal details and links.
- Add only project work you have actually completed.
- Replace "repository coming soon" labels with real repository links once projects are uploaded.
- Do not publish passwords, API keys, private data, credentials, or sensitive network information.
- Add screenshots and diagrams only when you have permission to share them.

## Customisation
Edit the text in `index.html` and visual styles in `style.css`. No build tools or framework are required.
